# 🍅 RETRO ARCADE POMODORO TIMER

A rad, retro arcade-style pomodoro timer that brings the 80s gaming aesthetic to your productivity workflow!

## Features

### ⏰ Timer Functionality
- **25-minute work sessions** (default)
- **5-minute short breaks** after each work session
- **15-minute long breaks** after every 4 work sessions
- **Visual progress ring** that shows time remaining
- **Session counter** to track completed pomodoros

### 🎮 Retro Arcade Design
- Authentic 80s arcade aesthetic with neon colors
- Classic "Orbitron" monospace font for that retro-futuristic feel
- Glowing neon borders with animated RGB cycling
- Scanline effects and CRT-style visual filters
- Color-coded modes (cyan for work, hot pink for breaks)
- Glitch effects and arcade-style animations
- Square wave sound effects just like classic arcade games

### 🔧 Customizable Settings
- Adjust work session duration (1-60 minutes)
- Customize short break duration (1-30 minutes)
- Set long break duration (1-60 minutes)
- Toggle sound notifications on/off
- Settings persist in browser storage

### 🔔 Retro Audio & Notifications
- **Authentic arcade sound effects** using square wave synthesis
- **Different melodies** for work completion vs break reminders
- **Button click sounds** for that classic arcade feel
- **Desktop notifications** with retro styling
- **Browser tab title** updates with remaining time
- **Visual feedback** with neon glow effects

### ⌨️ Keyboard Shortcuts
- **Spacebar**: Start/pause timer
- **R key**: Reset current session

### 📱 Progressive Web App Features
- Works offline (basic functionality)
- Responsive design for all devices
- Service worker ready (for future PWA enhancements)

## How to Use

1. **Open the timer**: Open `index.html` in your web browser
2. **Choose your mode**: Select Work, Short Break, or Long Break
3. **Start the session**: Click "Start" or press the spacebar
4. **Work focused**: Stay focused during work sessions
5. **Take breaks**: Use break time to rest and recharge
6. **Track progress**: Watch your completed pomodoros grow!

## The Pomodoro Technique

The Pomodoro Technique is a time management method developed by Francesco Cirillo:

1. **Work for 25 minutes** with full focus
2. **Take a 5-minute break** to rest
3. **Repeat 4 times**, then take a longer 15-30 minute break
4. **Track your completed pomodoros** to measure productivity
